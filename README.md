# 📝 Todo List PWA

A simple and lightweight Todo List web application built with pure web technologies and enhanced as a Progressive Web App (PWA).

---

## 🚀 Features

- ✅ Add/delete tasks
- ✅ Mark tasks as completed
- ✅ Tasks counter
- ✅ Clear completed tasks
- ✅ Dark / Light mode (saved)
- ✅ User name onboarding
- ✅ Data saved locally (LocalStorage)
- ✅ Works offline
- ✅ Installable on mobile (PWA)

---

## 🧰 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Bootstrap
- LocalStorage
- Service Workers
- Web App Manifest
- Netlify (Hosting)

---

## 📱 Progressive Web App (PWA)

This app supports PWA features:
- Installable on Android & iOS
- Offline mode using Service Worker
- App icon & splash screen
- Standalone app experience

### 📲 How to Install

#### iPhone (Safari only):
1. Open the app link in Safari
2. Tap Share ⬆️
3. Add to Home Screen

#### Android (Chrome):
1. Open the app in Chrome
2. Tap Install App
3. Done 🎉

---

## 📴 Offline Support

Once installed and opened at least once online, the app works fully offline.
